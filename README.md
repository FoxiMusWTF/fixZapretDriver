# fixZapretDriver

Утилита для восстановления работы обхода блокировок

## 🔍 Что это такое?

При запуске игры Rust встроенный античит **Easy Anti-Cheat (EAC)** замораживает `WinDivert` из за чего перестает работать обход.

## 🚀 Инструкция по установке и запуску

1. **Скачайте** актуальный `.bat` файл из этого репозитория.
2. Нажмите по нему правой кнопкой мыши и выберите **«Запуск от имени администратора»** (это необходимо для управления службами драйвера).
3. Дождитесь выполнения команд и радуйтесь жизни! Не закрывайте окно, пока скрипт не завершит работу и не напишет "Готово".

## ⚠️ Важное примечание

* **Безопасность:** Скрипт не модифицирует файлы самой игры Rust и не внедряется в процесс EAC, поэтому он безопасен и не приводит к игровому бану (VAC/EAC ban).
* **Открытый код:** Вы всегда можете нажать ПКМ -> *Изменить* на батнике, чтобы лично убедиться в наличии всего двух безопасных команд.
